# DeepSeek API Pricing 2026

An evidence-based guide to estimating DeepSeek API costs by model, cache-hit rate, token mix, and peak versus off-peak processing time.

The article uses DeepSeek's published pricing and token-usage documentation as checked on October 27, 2026. Prices and product availability can change; readers should recheck the linked first-party sources before approving a budget.

This repository contains the static files for the GitHub Pages publication. It does not include analytics, account credentials, API keys, private research records, or executable model calls.

## Site structure

- `index.html` — article, metadata, and structured data
- `assets/` — responsive cover and explanatory illustrations
- `robots.txt` — crawler policy
- `sitemap.xml` — single-page sitemap

The site is intended to be served from the `main` branch with GitHub Pages.
